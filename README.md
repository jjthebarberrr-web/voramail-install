# VoraMail iOS Installation

This repository hosts the VoraMail iOS app for over-the-air (OTA) installation on registered test devices.

## Installation

Open this URL in Safari on your registered iOS device:

**https://jjthebarberrr-web.github.io/voramail-install/**

## Requirements

- iOS 17.0 or later
- Device UDID must be registered in the provisioning profile
- Install via Safari browser (required for OTA installation)

## Files

- `index.html` - Installation landing page
- `manifest.plist` - OTA installation manifest
- `version.json` - Current version information
- `VoraMail.ipa` - Signed iOS application package

## Support

For installation issues, ensure your device UDID is registered with the development team.
